# Instruções do projeto

Leia docs/COMO_TRABALHAMOS.md (regras do Pedro e jeito de trabalhar: ramos, PR, prévias, arte, equilíbrio), docs/PASSAGEM_CLAUDE.md, AGENTS.md, LEIA_PRIMEIRO.md e docs/CONCEITO.md antes de alterar o jogo. Escreva tudo em português do Brasil. Modelos de prompt para o ChatGPT: docs/prompts-chatgpt.md. Scripts de arte e mapa: ferramentas/ (ver ferramentas/LEIAME.md); instale as travas da main com sh ferramentas/travas-git/instalar.sh. Preserve a distinção entre decisões e valores provisórios. Rode npm run check e npm test após mudanças. Use npm start; não há dependências para instalar nem etapa de build. Não sobrescreva data/save.json. O pacote idle-dbz-assets não está integrado nesta base.
