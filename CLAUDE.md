# Instruções do projeto

Leia docs/processo/COMO_TRABALHAMOS.md (regras do Pedro e jeito de trabalhar: ramos, PR, prévias, arte, equilíbrio), docs/processo/PASSAGEM_CLAUDE.md, AGENTS.md, LEIA_PRIMEIRO.md e docs/processo/CONCEITO.md antes de alterar o jogo. Escreva tudo em português do Brasil. Modelos de prompt para o ChatGPT: docs/processo/prompts-chatgpt.md. Scripts de arte e mapa: ferramentas/ (ver ferramentas/LEIAME.md); instale as travas da main com sh ferramentas/travas-git/instalar.sh. Preserve a distinção entre decisões e valores provisórios. Rode npm run check e npm test após mudanças. Use npm start; não há dependências para instalar nem etapa de build. Requer Node 24+ (a persistência usa o SQLite embutido node:sqlite). O progresso é salvo em data/jogo.db (SQLite); um data/save.json antigo é migrado automaticamente na primeira execução (vira save.json.migrado-*). Não apague nem sobrescreva data/jogo.db. O pacote idle-dbz-assets não está integrado nesta base.
